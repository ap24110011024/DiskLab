How the visualizer works

  1. Build a workload. Set the disk size, head position, direction and request queue in the Input Studio, or pick a preset.
  2. Run an algorithm. The algorithm produces a complete list of steps: every movement, distance and reason.
  3. Watch it. The 2D track, seek graph and 3D platter all replay those same steps, so the animation can never disagree with the calculation.
  4. Compare and test. Race the three algorithms, check them against test cases, and export the results.

How it is built

Algorithms
Plain JavaScript modules; each returns every step, distance and reason
2D views
SVG track and seek graph drawn from those steps
3D views
CSS perspective and transforms, no 3D library
Charts
Chart.js, bundled locally
Storage
LocalStorage for history and saved workloads; no server
Testing
In-browser test page plus a command-line runner
